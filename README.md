# AI Precision Agriculture Recommendation System

A Machine Learning based smart agriculture system that recommends the most suitable crop using soil nutrients and real-time weather conditions.

## Features

- Crop Recommendation using Machine Learning
- Real-time Weather API Integration
- Soil Nutrient Analysis
- Explainable ML Analysis
- Fertilizer Recommendation
- Alternative Crop Suggestions
- Recommendation History Storage
- Interactive Dashboard

## Technologies Used

- Python
- Streamlit
- Scikit-Learn
- Pandas
- NumPy
- SQLite
- OpenWeather API
- Plotly

## Machine Learning Models

Compared multiple ML algorithms:

- Random Forest
- Decision Tree
- SVM
- KNN
- Naive Bayes
